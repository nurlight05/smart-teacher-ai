Telegram Бот vs Веб Қосымша

Мұғалімдер үшін ең ыңғайлы формат — Веб Қосымша (Web App). Телефон браузерінен ашып, қосымша орнатпай-ақ камерамен тікелей жұмыс істей аласыз.

Telegram Бот форматы

Telegram бот арқылы да жасауға болады (Python aiogram + Gemini API). Мұғалім ботқа сурет жіберіп, пәнін таңдайды. Бірақ сыныптар мен оқушылардың үлкен кестесін телефон экранында көру үшін Веб Қосымша әлдеқайда визуалды әрі ыңғайлы!

Gemini API Кілтті енгізу

Нақты Gemini ЖИ арқылы тексеру үшін Google AI Studio арқылы алынған Gemini API кілтіңізді енгізіңіз.
